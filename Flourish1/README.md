# Flourish 1
## Description
This visualization shows the average hourly rate for employees of the City of Seattle by department. Each bar represents a unique department, sorted in descending order with a gradient for clarity and comparison. Data was sourced from City of Seattle's open data site, provided by the Human Resources Department and updated monthly. In excel, I rounded the values to the second decimal place for cleaner visualization. 

Source: [Seattle Open Data](https://data.seattle.gov/City-Administration/City-of-Seattle-Wage-Data/2khk-5ukd/about_data)
