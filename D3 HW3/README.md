# D3 HW3
## Description

This is a line chart showing GDP of US states in trillions of USD over time. Using the buttons, you can compare between the Top 5 states. 
The data was sourced from the US Department of Commerce, specifically from the Bureau of Economics Analyis. I cleaned the data in Excel. 
Chart made in VS Code, following the example template provided in class. I also reference W3 schools and MDN for extra resources.
